## Three engagement options

**Paid bounded pilot:** the buyer provides a synthetic test schema and measurable
written acceptance criteria. ARAZVERA adapts the applicable module under a
limited scope, then the buyer independently verifies the result.

**Private source licensing:** a nonexclusive module licence may be negotiated
after provenance, ownership, sector and legal review; private source is not
posted publicly and isn't transferred before approval.

**Customer-specific engineering:** real ERP interfaces, hosted authentication,
actual tool integrations, database adaptors and production operations are
separate technical projects with their own verification, contracts and prices.

## Operating constraints

The owner and developer genuinely resides in **Iran**. Both parties must
confirm permitted contracting, export/sanctions obligations, data processing,
source rights and legally allowed payment *before* transfer. No payment
instrument is suggested as a workaround. Customer owns and pays for any
production server, API account and third-party licences.

Technical collaboration is **English asynchronous writing only**, based on
real specifications, tests, technical documentation and AI-assisted English
editing. There are **no voice/video calls or spoken interviews**.
